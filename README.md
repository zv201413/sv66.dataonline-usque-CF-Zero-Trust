# usque-CF-Zero-Trust

轻量级代理部署方案，通过 Cloudflare MASQUE + Shadowsocks 为受限 Linux 环境提供加密隧道

**当前版本**: v2.0.0
**技术栈**: Shell, gost, usque, Cloudflare

---

## 🌟 核心特色

- 一键安装部署
- MASQUE 隧道加密
- Shadowsocks 加密出口
- IPv6 自动适配
- 配置文件备份复用

---

## 🚀 快速开始

1. curl 安装脚本
2. 获取 Zero Trust 令牌
3. 手动配置端口
4. 复制节点链接使用
